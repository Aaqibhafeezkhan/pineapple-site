    Direct reach for a bug

    For speed, include in your issue or email:

    • Device model + Android version (API level if known).
    • Steps to reproduce + tap-by-tap names.
    • Whether you're on Wi-Fi / cell / airplane mode.
    • Logcat snippet (Settings → Developer options → Take bug report) if the app crashes.
    • Screenshot (Settings > Account's screenshot) when UI issue.

    If requesting a device test, we bill at zero — but we do ask for the device-access itself, or at least synthetic offline/low-latency tests.
