    How to install the APK

    1. Download the APK from this page (or your phone directly).
    2. You'll see Install blocked — tap Settings on that dialog, then enable Install unknown apps for the browser/Files app you used.
    3. Confirm the install; open Pineapple from the launcher.

    Android 8.0 (API 26) or newer. Uninstall a previous Pineapple first if upgrading across build signatures (only from pm install dev builds — release signed builds upgrade in place).

    Source & verification

    Every tagged release is built from source and linked here. Source lives in the main GitHub repository; all development happens through opening PRs against main. The latest tip of main builds with assembleDebug / testDebugUnitTest (currently 40 unit tests passing). The release tag points to the exact commit of the published APK (tree tested via the dev.ps1 script).
